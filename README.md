# CopyRs

Copiatore di file leggero, gratuito e open source scritto in Rust: finestra compatta, coda di copia,
verifica CRC32, pausa / salta / annulla, gestione dei file già presenti e integrazione con Esplora file.

Build: `cargo build --release` -> `target/release/copyrs.exe`
Su GitHub: la compilazione per Windows parte da sola (scheda Actions, artefatto `copyrs-windows`).

Repository: https://github.com/gsepp86/copyrs
