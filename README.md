## CopyRs 2.3.0

Interfaccia professionale per la copia di file leggero, gratuito e open source scritto in Rust: finestra compatta, coda di copia, verifica CRC32, pausa / salta / annulla, gestione dei file già presenti e integrazione con Esplora file.

In questa nuova build è stato aggiunto il supporto in inglese (attualmente supporta italiano e inglese)

- Aggiunta lingua inglese nelle impostazioni
- Finestra stabile durante la copia (niente ridimensionamento in base al percorso)
- Corretto il calcolo del totale GB da copiare
- Auto-scroll e evidenziazione del file in copia
- Versione aggiornata
