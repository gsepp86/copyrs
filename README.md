## CopyRs – copia file in modo semplice e controllato

# Un copiatore di file leggero, gratuito e open source per Windows, scritto in Rust.

Quando copi file grandi o molti file contemporaneamente, Esplora file offre poco controllo. CopyRS ti dà una finestra compatta con una coda di copia, la verifica di integrità tramite CRC32 e la possibilità di mettere in pausa, saltare o annullare ogni operazione, senza appesantire il sistema.
Funzionalità

    Coda di copia con gestione di più operazioni in sequenza
    Verifica CRC32 per assicurarti che i file copiati siano identici agli originali
    Pausa, salta e annulla in qualsiasi momento
    Gestione dei file già presenti con opzioni di sovrascrittura o salto
    Integrazione con Esplora file
    Ultraleggero: nessuna dipendenza pesante, pensato per restare veloce e discreto
